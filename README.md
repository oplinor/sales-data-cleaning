# sales-data-cleaning
Sales Performance and Revenue Analysis with Python
Welcome to my sales data analysis project! I built this project using Python to clean raw retail data, run mathematical aggregations, and create visual charts to explore business performance.

About the Project
This project demonstrates how to analyze large sales datasets programmatically using Python libraries. The analysis tracks overall company revenue, evaluates yearly trends from 2009 to 2011, and identifies top-performing products and customer locations.

Key Highlights and Features
Data Cleaning and Preparation: Handled missing values, corrected data types (such as dates and numeric fields), and structured raw transaction records for analysis.

Revenue and Business Metrics: Calculated total company revenue ($19.29 million) and broke down sales performance across individual years (2009, 2010, and 2011).

Geographic Breakdown: Generated bar charts comparing total sales across different countries, highlighting major markets like the United Kingdom, Ireland, and the Netherlands.

Product Performance Insights: Visualized top-selling items to show which products generate the highest sales volume.

Data Visualization: Built clean bar charts and pie/doughnut charts using custom colors to make findings simple to read.

Tools and Libraries Used
Pandas: Used for loading, filtering, grouping, and transforming transactional data.

NumPy: Used for fast numeric operations and mathematical calculations.

Matplotlib: Used to create core chart layouts, figures, and customized axes.

Seaborn: Used to style data visualizations with modern color palettes and statistical charts.
